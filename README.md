# TCenter 1.3.4 临时编辑中心

原生 macOS 菜单栏应用，Swift + AppKit，无第三方运行依赖。

## 启动与更新

退出当前正在运行的 TCenter，再打开 `build/TCenter.app`。右键菜单栏回形针 →「关于 TCenter」确认版本为 1.3.4。替换应用包不会替换内存中仍在运行的旧进程。

```sh
zsh scripts/build.sh
open build/TCenter.app --args --show
```

## 挂绳

- 全局快捷键 **Control + Option + 空格（⌃⌥Space）** 展开或收起挂载线；无需辅助功能权限。若组合键已被其他应用占用，「关于 TCenter」会显示注册失败。
- 鼠标从下方移入任一屏幕顶部菜单栏横条（包括空白处）自动展开；停在顶部横条或挂载线内保持显示，离开两者后 3 秒收起。主动收起后，移出顶部横条再移入才重新触发。此范围也包括其他菜单项；不覆盖菜单栏或拦截其点击。
- 点击菜单栏回形针展开或收起；右键菜单可新建 MD/TXT/JSON/XML/CSV、导入文件、打开存储目录。
- 透明背景、横向挂绳、84 点高度；挂件居中，图片按比例显示，名称右侧显示时间。
- 左旧右新，按最后编辑时间排列；内容超出时横向滚动。
- 鼠标停留在整个挂绳区域内，或正在拖拽时保持展开。
- 鼠标离开、且没有拖拽时开始 3 秒倒计时；重新进入取消倒计时；拖拽在外部结束后重新计算 3 秒。
- 点击其他程序仍立即收起。点击挂件打开编辑窗口并收起挂绳。
- 展开后 Command+V 可挂载文件、图片或文字；也支持拖入文件。
- 拖出卡片使用 macOS 文件复制语义。点击 × 将 TCenter 副本移到废纸篓，原文件保留。

## 截图：只处理捕获会话中的新结果

截图目录不是自动导入列表。启动或切换系统截图保存路径时只记录现状，不挂载历史图片。

1. 通过系统截图工具启动/激活、截图工具栏从隐藏变为显示，以及可用时的截图快捷键事件，识别一次截图操作。
2. 建立会话开始时的目录基线；只接收会话开始后创建、基线中不存在且带系统截图标记或常见截图文件名的新图片。
3. 等待文件大小和修改时间稳定，复制到 TCenter；每次会话成功导入一张即结束。原图保留。
4. Esc（系统允许观测时）取消；工具栏消失后保留 30 秒落盘等待；会话最长 120 秒。到期关闭，不回扫历史补偿。
5. 文件身份和内容 SHA-256 写入 `screenshot-history.json`；删除挂件不删除处理记录，重启、重命名副本或原文件修改不会使已识别截图自动复活。
6. 剪贴板图片仅在捕获会话中接收：系统目标为剪贴板、按下 Control 截图，或图片带截图来源类型时，接受新的 PNG/TIFF/HEIC/HEIF 数据；剪贴板模式不依赖桌面目录权限。会话外复制图片不会自动挂载。识别不到截图事件时使用 Command+V。
7. 文件模式支持 PNG、HEIC、HEIF 等图片格式；浮动缩略图仍在编辑时，需等系统实际保存后才能挂载。

边界：剪贴板没有可靠的统一截图来源标记。在等待剪贴板截图的会话期间，主动复制其他图片也可能被作为本次结果接收。

工具栏可见性与系统应用通知不要求新增辅助功能授权；全局快捷键与 Esc 事件能否收到取决于系统现有权限。截图目录访问失败或历史记录损坏时，自动导入会暂停或显示原因；可在「关于 TCenter」查看状态。

历史记录先持久化再复制，避免崩溃后重复导入；若进程恰好在这两步之间退出，可能需要手动挂载该张截图。升级前已导入的历史挂件保留，可自行删除；不会自动清空用户资料。

## 编辑器

| 类型 | 功能 |
| --- | --- |
| MD / Markdown | 文本编辑；基础标题、列表、粗体、行内代码、代码块预览 |
| TXT | 原生文本编辑、剪切复制粘贴与撤销 |
| CSV | 表格逐格编辑、增加/删除行列、源码切换；支持引号、转义、多行和 CRLF |
| JSON | 树状字段、值、类型编辑，增加/删除节点，源码切换 |
| XML | 元素、属性、文本和注释树，名称和值编辑，增加/删除节点，源码切换 |
| 图片 | 按比例预览常见图片格式，解码支持以 macOS 为准 |

文本和 CSV 停止输入 350 毫秒后保存；树状字段结束编辑后校验保存。关闭窗口、退出前立即保存；保存失败时阻止关闭。关闭编辑窗口不删除挂载。

## 存储与检查

- 便签副本：`~/Library/Application Support/TCenter/Files/`
- 截图已处理记录：`~/Library/Application Support/TCenter/screenshot-history.json`
- 构建：`zsh scripts/build.sh`
- 核心检查：`build/TCenter.app/Contents/MacOS/TCenter --self-test`
- 隔离界面与场景回归：`build/TCenter.app/Contents/MacOS/TCenter --ui-test`
- 验证范围见 `VALIDATION.md`。测试使用工程内独立目录，不使用正式截图目录。

文本读取 UTF-8 或带 BOM 的 UTF-16，保存统一为 UTF-8。JSON 树状保存重新缩进和排序键；XML 序列化可能调整格式细节，禁止外部实体加载。Markdown 为基础预览子集。当前为 Apple Silicon 本机临时签名包，未进行 Developer ID 公证；主要面向小型临时文档。
